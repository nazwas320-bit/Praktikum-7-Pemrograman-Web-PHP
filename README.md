## D. Cara Menjalankan Program
1. Buka aplikasi MAMP.
2. Jalankan layanan Apache.
3. Simpan folder Lab7Web_PHP di dalam folder web server MAMP.
4. Buka Visual Studio Code.
5. Buka file PHP yang ingin dijalankan.
6. Buka browser dan akses alamat berikut:

`http://localhost:8888/Lab7Web_PHP/`

7. Tambahkan nama file PHP pada alamat tersebut untuk membuka latihan tertentu.

Contoh:
`http://localhost:8888/Lab7Web_PHP/latihan1.php`

## E. Ringkasan Praktikum

### Latihan 1 – Menjalankan PHP
Membuat program sederhana untuk menampilkan teks dan waktu server menggunakan PHP.

### Latihan 2 – Variabel, Operator, dan Percabangan
Menggunakan variabel dan operator untuk menghitung nilai akhir serta menentukan predikat.

### Latihan 3 – Perulangan dan Array
Membuat daftar mahasiswa menggunakan array dan perulangan foreach.

### Latihan 4 – Function
Membuat function untuk menghitung harga setelah diskon dan luas persegi panjang.

### Latihan 5 – Form GET
Membuat formulir pencarian sederhana menggunakan metode GET.

### Latihan 6 – Form POST
Membuat formulir data mahasiswa menggunakan metode POST.

### Latihan 7 – Pengolahan Data Sederhana
Membuat formulir transaksi barang dan menghitung subtotal berdasarkan harga dan jumlah.

### Mini Project – Formulir Data Mahasiswa
Membuat aplikasi formulir data mahasiswa yang memiliki validasi nama, NIM, program studi, semester, dan email.
